# 🎬 Kollywood Clash

### Guess the Movie. Beat the Clock. 🏆

**Kollywood Clash** is a real-time multiplayer Tamil movie guessing game where players compete to identify movies using clues before the timer runs out.

### ✨ Features

- 🎮 Multiplayer modes — **2 to 10 players**
- 🔴🔵 **Team Battle** — 2v2, 3v3, 4v4 and 5v5
- 🎬 Tamil movie clues with story, actors, director and poster
- ⏱️ Timed rounds with competitive scoring
- ⚡ Real-time room and gameplay synchronization
- 🖼️ TMDB-powered movie posters and metadata
- 📱 Responsive design for mobile, tablet and desktop
- 🏆 Individual and team scoreboards

### 🛠️ Tech Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS  
**Backend:** Supabase, PostgreSQL, Realtime  
**Movie Data:** TMDB API  
**Deployment:** Vercel

### 🚀 Run Locally


Create a `.env` file with your Supabase credentials before running the project.
